# Fonts

Source Sans 3, Source Serif 4 and Source Code Pro, by Adobe, under the SIL Open
Font License 1.1 (the OFL files beside this one). Each file here is Adobe's own
static WOFF2 build from a tagged GitHub release, unmodified — an Original
Version, not a subset, so the Reserved Font Name `Source` stands:

- Source Sans 3 400/500/600/700 — `adobe-fonts/source-sans` release `3.052R`
  (https://github.com/adobe-fonts/source-sans/releases/tag/3.052R)
- Source Serif 4 400/600 — `adobe-fonts/source-serif` release `4.005R`
  (https://github.com/adobe-fonts/source-serif/releases/tag/4.005R)
- Source Code Pro 400/500 — `adobe-fonts/source-code-pro` release
  `2.042R-u/1.062R-i/1.026R-vf`
  (https://github.com/adobe-fonts/source-code-pro/releases/tag/2.042R-u%2F1.062R-i%2F1.026R-vf)

Served by the install itself rather than from a font service, so that an
operator's browser never asks a third party for anything while using the
interface.
